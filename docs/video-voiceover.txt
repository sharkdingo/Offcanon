Offcanon 视频旁白（按顺序朗读；括号内为停顿提示）

01（开场）这是 Offcanon。Agent 不直接改主线，而是在隔离实验中提出候选，系统用可信证据决定是否晋级。
02（展示基线失败）今天修复一个南京大学标题的 Unicode slug 边界问题，基线四个测试中有一个失败。
03（发送任务）我要求它先定位、最小修改、补回归测试，再运行验收。
04（活动时间线）模型只产生结构化工具调用，AgentLoop 校验后顺序分发；读写都在实验区，主线不对 Agent 开放。
05（封存）完成只是模型声明。结果先封存，再在一次性工作区独立验收。
06（变更）审阅页显示实际差异和新增回归测试。
07（证据）证据记录命令、工作目录、退出码和快照；Agent 的 shell 输出只是观察。
08（指纹）应用前比较基线、当前主线和结果指纹；主线变化就标记过期，不覆盖、不猜测合并。
09（确认）我确认后才写回主线，不自动创建 Git 提交。
10（收尾）循环、工具、上下文限制和状态机由我实现，没有 Agent 框架。隔离是应用级的，不是操作系统沙箱。
